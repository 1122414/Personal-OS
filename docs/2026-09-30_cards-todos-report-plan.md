# 卡片参考资料、待办排序提醒与工作日报计划

## 已确认的决定

- **重复生成（bug）**：一次「现在生成」出现两批，是开启每天推送后自动推送与手动生成并发。手动生成也记为今天已推送；同一主题同一时间只允许一次生成。
- **卡片参考资料**
  - 主题「资料」页可上传 md / txt / pdf：md、txt 读成一条记录（正文即文件内容），pdf 作为附件并自动提取文字；都关联到当前主题。
  - 主题关联的全部资料默认用于生成卡片，可单独关掉某一份。
  - 学习页顶部有「通用参考」（所有主题生成卡片时都会看的规则，可写可导入 md），只用于卡片生成。
  - 提示里说明两类资料：简历、目标这类背景资料用于决定出什么题、答案结合自身经历；知识库这类资料是答案第一依据。资料外补充的内容要标明。每张卡片记下依据的资料名。
  - 资料总量有上限，超出按份截断并在结果里说明；未提取文字的 PDF 不使用并提示。
- **卡片外观**：主题卡片页一次显示一张大卡片，点击翻面，左右切换，显示序号；完整列表收进「管理全部卡片」。首页今日学习用同样的卡片样式。
- **待办**
  - 优先级 低 / 中 / 高，新待办默认中，彩色标签；编辑框可改。
  - 拖动排序：待办池、今天两栏内排序，也可在两栏之间拖；首页「今天」列表同样可排序。顺序完全由拖动决定。
  - 每晚 20:00 弹框列出「今天」栏未完成的待办，可直接勾掉；20 点时客户端没开，则当晚（24 点前）打开时补弹一次；每天只弹一次。客户端不在前台时同时发 Mac 通知。
- **审核**：从侧栏去掉（页面保留）。待验收任务照常在「Agent 任务」页处理；有待确认的知识写入时在任务页顶部提示并链接过去。
- **工作日报**：「历史」改名「工作日报」。由所选通道（Codex / Kimi / Claude Code / Cursor / WorkBuddy）生成「今日工作总结」和「明日工作计划」两部分，依据当天完成与未完成的待办、Agent 任务、代码提交与会话、决策；时间线保留在旁边作为依据。首页「生成今日日报」改为跳到工作日报页。

## 阶段

1. 修复重复生成 + 测试。
2. 卡片参考资料（上传、开关、通用参考、提示与依据）+ 测试。
3. 卡片外观（主题卡片页、首页今日学习）。
4. 待办优先级、拖动排序、20 点提醒 + 测试。
5. 审核移出侧栏；工作日报多通道生成 + 测试。
6. 浏览器与客户端测试实例验证（`/tmp` 数据），验收记录、README，重建客户端。

每阶段 `npm run check` 通过后单独提交。真实 AI 调用只在 `/tmp` 数据上做，尽量少。
