# Separate product identity from a personal theme

- Signals: UI documents call the workspace “属于博士自己的数字工作空间”; supplied home references include Skadi artwork and additional navigation items.
- Mechanism: descriptive copy from one personalized skin can be mistaken for the universal product identity or feature scope.
- Supporting case: on 2026-09-23 the user corrected this interpretation: Personal OS must remain general-purpose; 博士 is the Arknights protagonist's title, used by the developer personally; 浊心斯卡蒂 supplies the current theme imagery.
- Handling: distinguish generic product workflow from configurable nickname, character, artwork, and palette. Preserve supplied originals, but derive generated inner-page navigation from the product scope. Map themes by visual appearance, not greetings embedded in reference images.
- Limits: this clarification does not itself specify a full theme marketplace, avatar system, or additional V0.1 implementation work.
- Evidence: [asset index](../../reference-assets/README.md), [UI document](../../Personal-OSUI设计文档.md). User clarification confirmed once; this record is a design interpretation, not a software verification result.
