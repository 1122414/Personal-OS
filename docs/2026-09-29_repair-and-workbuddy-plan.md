# 稳定性修复与 WorkBuddy 接入计划

范围：修复审查报告 R01–R12 的实际缺陷，补齐本地长期使用所需的最小维护能力；WorkBuddy 作为信息来源接入。学习记录、点子记录、规则领悟模块继续不实施。

## 阶段与验收

1. 工作事实可靠性（R01–R05、R09、R10）：日报过期检查与保留旧稿的刷新、正确的历史日期及简报上下文、阻塞可见、所有 Agent 终态的文件证据、规则与决策传入、按日期加载历史与补记。验收覆盖晚到事件、人工编辑、失败/取消/重启和 1,000 条事件边界。
2. 日常维护（R06–R08、R11–R12）：计划选择/排序/修订、订阅日期和错误反馈、忽略项过滤、准确入口文案、任务归档/重开、可验证的备份恢复。高级推荐学习、自然语言解析、后台常驻与独立 Python 分发继续后置，并明确展示能力边界。
3. WorkBuddy：核实官方 API 与本机数据结构，采用可验证的只读来源；显示来源、时间、同步结果，去重更新，用户可转成任务或知识。不得直接把外部会话等同于已完成任务。核验本机读取后完成隔离集成测试、浏览器验收与 macOS 重建。

每阶段通过 Python 回归测试、前端构建和适用的直接验收后，以中文提交。保留原有未跟踪文档。外部来源数据不纳入 Git、不读取认证文件、不修改 WorkBuddy 源数据。
