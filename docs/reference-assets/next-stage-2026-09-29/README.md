这些是不可交互的首轮概念图，没有修改真实应用。图中的 Python/英语主题、文件、日期和记录均为虚构展示内容，不表示用户实际学习情况、连接状态或已实现功能。生成文字以产品规格为准，不能直接作为实现数据。

## 检视结果

- 两张图延续了现场界面的夜间视觉，并保留旧有导航，新增记录与学习入口。
- 首页突出先保存与继续学习；学习页将总结正文、来源及关联记录分开，显示人工编辑与手动选择 Agent 的入口。
- 学习页明确显示“已讨论，尚无独立练习记录”，不使用掌握率或虚构学习进度。
- 仅检查了概念图的主要内容和视觉层级；真实可点击区域、滚动、窗口缩放、键盘访问、空态、错误态和其他主题仍需后续交互设计与实现验收。其他主题不在本轮重复生图。
- 正式实现应把主题目标明确标为目标，完整保留拒绝再推荐、修订历史与生成失败等规则；概念图未将每个状态全部展开。

完整准确的两次生成提示词见 [prompts.json](prompts.json)。本轮使用内置工具，未使用 CLI/API 备用路径。
