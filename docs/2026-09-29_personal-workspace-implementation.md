1. **A1 记录与主题**：无分类快速保存；记录搜索、类型/主题筛选、编辑；文字/链接/图片/PDF 原件；主题关联、原文入口、明确转任务、Markdown/Obsidian 导出。检查 A01、A02、A09 保存边界、A12、A13，构建与现有回归后中文提交。
2. **A2 持续学习**：Codex 原生会话、流式消息持久化、两种学习模式、主动选择资料、解析范围/使用证据、取消/失败/重启恢复。检查 A03、A05、A09 及协议故障测试，执行隔离的真实运行时验证后中文提交。
3. **A3 可修改总结**：静默调度、来源快照、结构化 Markdown 总结、逐部分自动保存、人工保护、候选变化、版本恢复和导出。检查 A04、A06–A08 的并发、失败与来源边界后中文提交。
4. **A4 找回与状态**：明确状态及期限、推测确认、上下文关联和每周最多三条回顾，完成首页与主题概念图对应界面。检查 A10、A11、A14；完整构建、自动化和界面流程检查后中文提交。

每阶段检查差异和暂存区，只提交本任务文件。用户原有三个未跟踪设计文档不纳入提交。不会推送或更改现有提交历史。

## 设计系统与界面边界

- 沿用 `public/theme` 三个背景和当前可调透明度；夜间基色为深蓝黑、冷色细边框、白色文字、灰蓝辅助文字、绯红主操作。保留右上人物，背景不叠加新的色罩。
- 左侧固定导航新增记录/学习，设置靠底部。首页简短问候 → 全宽随手记 → 左宽继续学习/右窄状态与任务 → 最近记录/每周回顾。今日计划完整操作保留在首页的工作视图。
- 学习主题使用总结/对话/资料标签，主阅读区与右侧来源/关联记录分栏。正文使用已有安全 Markdown 组件，标题使用现有中文衬线字体，表单和正文使用现有无衬线字体。
- 复用 Button、Panel、Field、Modal；扩展有边框列表行、来源链接、总结部分、消息列表。圆角 10–14px、区块间距 12–16px；表单可聚焦、状态不只靠颜色表达。
- 概念图中的例子不是生产种子数据。未绘制的记录编辑、失败、空白状态延续同一视觉系统；窄窗口转单列且所有主操作可滚动到达。

## 数据与验证策略

- POS 原始消息/记录是主数据；Codex 会话 ID 仅为运行时关联。学习默认只读，不能沿用项目写入权限。
- 图片与 PDF 的 BLOB 纳入 SQLite 备份；API 状态响应只返回元数据。限制格式、大小，文件名不作为磁盘路径。
- 自动生成依据来源版本，不覆盖人工修订；故障和中断必须可见。用确定性协议夹具覆盖错误、取消与并发，再做小规模真实 AI 验证。
- 每阶段记录实际命令和结果；真实内容质量及跨日使用效果与自动测试结果分别陈述。
