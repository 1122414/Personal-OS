# 主题透明度与 Obsidian AI 日报阅读

用户要求：主题透明度能在设置中调整；工作台直接阅读 WorkBuddy 已写入 Obsidian 的 AI 日报，替代默认展示无用会话摘要。

## 实施与验收

- T01：设置提供 0–100% 面板/侧栏背景透明度，即时预览、保存、重启保持；文本不跟随变淡，三个主题均适用。后端拒绝越界、非数字和布尔值。
- D01：使用已配置 vault 的 `每日AI/YYYY-MM-DD/*.md` 作为只读正文来源，默认最新一期、可选日期，区分今天未发布；首页展示入口。设置可调整 vault 内的日报子目录。
- D02：情报默认 AI 日报；会话记录独立次要入口，不进入首页和 AI 简报。停用本机原会话自动同步，保留已收录数据供回看。
- D03：正文支持标题、列表、勾选状态、表格、代码和安全链接；不执行 HTML，不自动加载远程图片。拒绝越界/符号链接/非日报文件；缺失文件、格式错误、过大文件应明确提示。读取失败不能保留旧正文冒充当前文件。
- 验证：隔离单测覆盖来源边界、日期排序/更新、只读哈希、旧设置兼容和参数校验；浏览器核验正文与透明度预览/保存；完整 Python 测试、前端/macOS 构建与签名检查。真实笔记只读，不复制正文到仓库或修改笔记。

本轮一个实施阶段，验证后中文提交。保留三个原有未跟踪文档。未定义的新记录模块不实施。

## 使用

1. 设置 → 外观主题 → 界面背景透明度，拖动预览后“保存设置”。
2. 首页 → AI 日报 → 点报告，或情报 → AI 日报。日期列表可看以前各期；AI HOT、SmartRun、MUA、前沿雷达以及同日期周报均在列表中。
3. WorkBuddy 后续把 Markdown 写进 `每日AI/YYYY-MM-DD/` 后，工作台会检查并显示；也可点“刷新”。此功能不需要启用 WorkBuddy 会话同步。
4. 要改笔记或勾选原文任务请在 Obsidian 操作，工作台刷新后展示更新。当前不执行 HTML、Obsidian 插件或加载内嵌远程图片。

复用并修正 [外部来源经验](experience/patterns/external-session-import.md)：技术上导入成功不能证明选对了用户要阅读的资料；应先核对成品文档的位置。
