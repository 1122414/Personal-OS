## 执行方式

- `npm run check`：Vite 生产构建和 `python3 -m unittest discover -s tests -q`，最终 90 项通过，无新依赖。
- `./scripts/build-macos-app.sh`：Swift Mac 容器、PDFKit 助手、前端和服务一并打包。
- 包内隔离加载检查：在应用 runtime 中导入 Store，创建临时数据库，核对记录/学习/状态字段、前端与 PDF 助手均存在；禁用字节码写入，未更改签名资源。
- `codesign --verify --deep --strict 'build/Personal OS.app'`：签名验证通过。
- Codex 实际安装版本 `0.155.0-alpha.16.4`：真实两轮原生会话和一次有效总结完成。协议错误、退出、取消、权限请求及会话恢复由确定性测试覆盖；没有以模型全文相等代替内容验收。
- UI 使用内置浏览器，后端为 `/tmp` 下的隔离 SQLite，自动调度关闭；手工触发真实学习/总结。没有写入正式个人数据库。状态时间和旧记录年龄边界由测试夹具控制。
- 窗口检查覆盖实际 CSS 视口 1440×900、约 818×563、391×818，正文没有横向溢出；小窗口的主内容可滚动。跨页后内容滚动归零，消息引用仍定位到对应原话；控制台未发现 error/warn。
- 仓库没有既有 CI，本次提供统一 `npm run check`，未声称远端 CI 已运行。

## 视觉核对与剩余限制

对照已接受的首页/学习总结概念图，保留现有夜间背景、左侧导航、绯红操作、中文衬线标题和半透明面板。首页使用快速记录、继续学习、状态/任务、最近记录/周回顾；主题使用总结/对话/资料与来源分栏。真实记录数量、正文长度和可用来源决定面板高度，不使用概念图示例填充生产数据。实际截图位于 [界面验收素材](verification-assets/2026-09-29-workspace/README.md)。

本次确认的是实现、协议和短程交互。总结是否长期有用、推荐是否打扰、跨日学习能否自然接续，还需要真实使用反馈。匹配目前是本地共同词语规则，适合可解释的首版，尚无语义检索；图像理解取决于所配 Codex 模型；PDF 没有 OCR；网页不运行 JavaScript；手机/云服务尚未建设。Mac 包仍依赖本机 Python 3.12+ 与已登录 Codex。没有执行长时间原生窗口浸泡或生产数据回归。
