# 个人工作台维护：正确性与可读性

范围：学习上下文与草稿、每周回顾、本机 HTTP 输入边界。基线为 `6ed1150`，构建与 90 项 Python 测试通过；本次不等同于全仓审计。

## 阶段

1. 先补回归测试，修复回顾缓存、总结来源版本和请求边界；检查通过后中文提交。
2. 整理学习页组件与异步状态，验证切换标签、发送期间编辑、请求乱序；检查通过后中文提交。

## 验收条件

| ID | 场景 | 修复前预期（待复现） | 修复后验收 |
| --- | --- | --- | --- |
| M01 | 本周先运行一次空回顾，再出现符合条件的旧记录 | 空缓存阻止本周生成 | 本周仍可生成一次；已有非空回顾、反馈与最多 3 条限制保留 |
| M02 | 记录参与对话后被编辑或取消关联，再生成总结 | 发送时的记录版本遗漏 | 保留当时原文与版本；新旧版本区分，导入资料不冒充用户意图 |
| M03 | HTTP Host/Origin 格式损坏、总结历史 key 类型错误 | 未捕获异常 | 拒绝请求或返回校验错误；合法本机访问保持可用 |
| M04 | 写问题、选择资料后切换标签；发送等待中继续输入 | 草稿丢失，或后输入内容被发送成功回调清空 | 标签往返保留草稿与选择；成功只清理已提交草稿，失败保留可重试 |
| M05 | 学习详情的旧请求晚于新请求返回 | 旧响应覆盖新界面 | 仅最新请求可更新详情；卸载后的响应无效 |

沿用现有 Python 测试与 Vite 构建；前端纯状态逻辑使用 Node 内置测试，无新增依赖。真实界面使用隔离数据库，避免改动日常数据。未发送草稿的本次承诺限于同一主题的标签往返，不包含退出应用后的持久恢复。

## 阶段一结果

M01–M03 已通过新增测试复现并修复：空回顾随后可填充且不重复补位；被修改或取消关联的历史记录原文不再消失；损坏的 Host/Origin 和非字符串历史部分 key 得到校验错误。总结来源约定版本升级，旧报告会进入待更新状态，人工部分仍走候选保护。完整检查通过：构建成功，96 项 Python 测试通过。
